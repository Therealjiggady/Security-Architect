## Getting Started

### Prerequisites

-   Figma account to view .fig files
-   PDF reader for the documentation
-   Git or other version control system

### Installation

1. Clone the repository:
   git clone https://github.com/your-username/broke_n_beauty_ecommerce.git

2. Navigate to the folder:
   cd version_control_1

3. Open the Figma file in Figma application or web version.

4. Open the PDF with any PDF viewer.
