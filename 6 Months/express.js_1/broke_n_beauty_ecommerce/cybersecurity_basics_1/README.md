## About

This folder contains basic cybersecurity resources and assessments for securing the Broke N Beauty Ecommerce application.

-   What is this project? A repository of introductory security documents and threat analyses.
-   What problem does it solve? Provides fundamental knowledge and tools for identifying and managing cyber threats.
-   Who is it for? Beginners in cybersecurity and developers learning security practices.
-   What makes it unique? Includes practical examples from OWASP Juice Shop and incident response basics.

-   Incident response plans
-   Risk management reports
-   Security scan results

## Getting Started

### Prerequisites

-   PDF reader for reports
-   Excel viewer for spreadsheets
-   Text editor for scan files

### Installation

1. Clone the repository:
   git clone https://github.com/your-username/broke_n_beauty_ecommerce.git

2. Navigate to the folder:
   cd cybersecurity_basics_1

3. Review the documents with appropriate viewers.
