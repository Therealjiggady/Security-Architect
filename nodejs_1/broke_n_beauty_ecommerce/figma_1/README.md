## About

This folder contains design files and related documentation for the Broke N Beauty Ecommerce project.

-   What is this project? A design asset repository for the ecommerce platform.
-   What problem does it solve? Provides visual designs, security knowledge, and additional design resources for development.
-   Who is it for? Developers and designers working on the ecommerce site.
-   What makes it unique? Includes Figma files, cybersecurity documentation, and a Jam file for collaborative design.

## Getting Started

### Prerequisites

-   Figma account to view .fig files
-   PDF reader for the documentation
-   Figma Jam access for .jam files

### Installation

1. Clone the repository:
   git clone https://github.com/your-username/broke_n_beauty_ecommerce.git

2. Navigate to the design folder:
   cd figma_1

3. Open the Figma file in Figma application or web version.

4. Open the PDF with any PDF viewer.

5. Access the Jam file via Figma Jam.

---

## Usage

-   Use the Figma file to review and implement UI designs for the ecommerce site.
-   Refer to the cybersecurity PDF for best practices in securing the application.
-   Use the Jam file for brainstorming and collaborative design sessions.
