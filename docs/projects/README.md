# Broke N Beauty Projects

This directory contains Python applications developed for the Broke N Beauty clothing line. These applications provide various functionalities to enhance the customer experience and streamline operations.

## Project List

1. **SmartFit Size Recommender** (clover_smartfit_gui.py)
   - Python Tkinter app for personalized clothing size recommendations
   - Features user measurement input, brand-specific sizing database, and personalized recommendations

2. **Contact Form System** (Contact_Form.py)
   - Support ticket management system for customer inquiries
   - Stores support tickets in CSV format with timestamps

3. **Delivery Tracker** (Delivery Tracker.py)
   - Tool for estimating delivery dates based on processing time
   - Provides user-friendly interface for shipping estimates

4. **Wishlist Application** (Wishlist.py)
   - Application for creating and managing product wishlists
   - Allows adding/removing items and exporting wishlists

5. **Help Center & FAQs** (FAQS.py)
   - Interactive help center providing clothing care tips and information
   - Features categorized help topics and pop-up information dialogs

## Technology Stack

All applications are built using:
- Python
- Tkinter for GUI
- CSV for data storage (where applicable)
- File I/O for saving and loading data
